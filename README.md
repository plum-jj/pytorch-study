# pytorch-study

PyTorch 예제를 직접 따라 치고, 코드에 주석을 남기며 학습하는 저장소입니다.

## 참고 자료

- 원본: [프로젝트로 배우는 파이토치 딥러닝](https://github.com/kairos03/Learning-PyTorch-Deeplearning-with-Hands-On-Projects)
- 원본 저장소의 코드를 참고한 부분은 해당 출처와 주석을 유지합니다.
- 원본 예제를 미리 복사하지 않고, 학습하면서 직접 작성합니다.

## 구성

| 폴더 | 학습 내용 |
| --- | --- |
| Part1 | Pandas, 시각화, 퍼셉트론, XOR |
| Part2 | 사인 함수 예측, 당뇨병 진행도 예측, 붓꽃 분류 |
| Part3 | CNN, VGG·ResNet, 전이학습, 흉부 X-ray 분류 |
| Part4 | 객체 탐지, 오토인코더, U-Net, 이미지 생성 |
| Part5 | RNN, 품사 태깅, 트랜스포머 |
| notes | 학습 메모 양식 |

각 파트에 `.ipynb` 또는 `.py` 파일을 만들어 실습합니다.

## 학습 방법

1. 코드를 직접 입력하고 셀·블록 단위로 실행합니다.
2. 입력/출력 텐서 크기와 코드의 역할을 한국어 주석으로 적습니다.
3. 오류 원인과 해결 방법을 해당 파트 README에 기록합니다.
4. 학습한 내용을 내 말로 정리한 뒤 커밋합니다.
